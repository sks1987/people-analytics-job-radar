How this page is built

A GitHub Actions workflow runs fetch_jobs.py once a day. It queries the Adzuna API for Germany and a set of EU countries, and the Jooble API for the UAE, keeps only listings whose title/description contain both an HR term and an analytics/data term, de-duplicates, and re-renders this page into docs/index.html — which GitHub Pages then serves automatically.
